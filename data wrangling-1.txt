## 1. Understand your practical first

Aim: To perform basic data-wrangling operations on the Iris dataset using Python libraries.

What is Data Wrangling?

Data wrangling is the process of cleaning, organizing and transforming raw data into a useful format for analysis.

Example:

- Finding missing values.
- Removing duplicate records.
- Dropping unnecessary columns.
- Replacing text values with numerical values.
- Understanding the dataset.

### 4. Find duplicate records

```
df.duplicated()
```

Checks whether rows are duplicated.

- True = Duplicate row.
- False = Not a duplicate row.

Q. How do you remove duplicates?

```
df.drop_duplicates()
```

### 5. Find missing values

```
df.isnull()
```

Checks whether values are missing.

- True = Missing value.
- False = Value is present.

Q. How do you count missing values?

```

```

Your dataset has zero missing values in every column.

### 6. Display dataset information

```

```

Displays:

- Number of rows.
- Number of columns.
- Column names.
- Data types.
- Non-null values.
- Memory usage.

Q. What is dtype?

It represents the data type of a column, such as integer, float or object.

### 7. Find dataset dimensions

```

```

Output:

```

```

It means:

- 150 rows.
- 5 columns.

Q. What is the difference between shape and size?

- `size` returns the total number of elements.

### 8. Check missing values in a particular column

```

Checks missing values only in the `sepal.length` column.

### 9. Drop a column

```

Removes the `petal.length` column from the resulting DataFrame.

Important:

- `axis=0` means rows.
- `axis=1` means columns.

Replaces:

Why do we convert text into numbers?

Many machine-learning algorithms require numerical input.

Note: Your code does not replace Versicolor, so it remains unchanged.

## 6. Important differences for viva

Pandas Series vs DataFrame

| Series                | DataFrame           |
| --------------------- | ------------------- |
| One-dimensional       | Two-dimensional     |
| Single column of data | Multiple columns    |
| Like a single list    | Like an Excel table |

`isnull()` vs `dropna()`

| isnull()               | dropna()                           |
| ---------------------- | ---------------------------------- |
| Detects missing values | Removes missing-value rows/columns |
| Returns True or False  | Returns cleaned data               |

`head()` vs `tail()`

| head()         | tail()         |
| -------------- | -------------- |
| First records  | Last records   |
| Default 5 rows | Default 5 rows |
