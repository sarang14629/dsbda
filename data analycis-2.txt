# Confusion Matrix – Explanation (Machine Learning)

This image shows a Confusion Matrix used to evaluate the performance of a Machine Learning classification model.

Let's understand it in simple English for your practical viva.

## 1. What is a Confusion Matrix?

A confusion matrix is a table that compares the model's actual predictions with predicted results.

It tells us:

- How many predictions are correct.
- How many predictions are incorrect.
- How accurately the model identifies positive and negative classes.

## 2. Understanding your Confusion Matrix

Your output:

Confusion Matrix

|          | Predicted 0          | Predicted 1         |
| -------- | -------------------- | ------------------- |
| Actual 0 | 61<br>True Negative  | 2<br>False Positive |
| Actual 1 | 10<br>False Negative | 27<br>True Positive |

There are four important terms:

| Term                | Value | Meaning                                  |
| ------------------- | ----- | ---------------------------------------- |
| True Positive (TP)  | 27    | Correctly predicted positive             |
| True Negative (TN)  | 61    | Correctly predicted negative             |
| False Positive (FP) | 2     | Predicted positive but actually negative |
| False Negative (FN) | 10    | Predicted negative but actually positive |

Easy trick to remember:

- True = Correct prediction.
- False = Wrong prediction.
- Positive = Class 1.
- Negative = Class 0.

## 3. Understanding performance metrics

Your notebook gives these results:

# 88%

Accuracy

# 93%

Precision

# 73%

Recall

# 12%

Error Rate

### A. Accuracy

Accuracy tells us how many predictions are correct out of total predictions.

Formula:

\\[ Accuracy=\frac{TP+TN}{TP+TN+FP+FN} \\]

\\[ =\frac{27+61}{100}=0.88 \\]

Answer = 88%

### B. Error Rate

It tells us how many predictions are incorrect.

\\[ Error Rate=\frac{FP+FN}{Total} \\]

\\[ =\frac{2+10}{100}=0.12 \\]

Answer = 12%

### C. Precision

Precision tells us how many predicted positive values are actually positive.

\\[ Precision=\frac{TP}{TP+FP} \\]

\\[ =\frac{27}{27+2}=0.93 \\]

Answer = 93%

### D. Recall

Recall tells us how many actual positive values the model correctly identified.

\\[ Recall=\frac{TP}{TP+FN} \\]

\\[ =\frac{27}{27+10}=0.73 \\]

Answer = 73%
