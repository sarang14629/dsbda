### B. Sentence Tokenization

Important

```
var1 = sent_tokenize(text)print(var1)
```

Sentence Tokenization means splitting a paragraph into individual sentences.

Input

Hello everyone! I am a student. I like Python.

Output

```
[  'Hello everyone!',  'I am a student.',  'I like Python.']
```

Viva: What is the purpose of sentence tokenization?

Answer: It divides a paragraph into separate sentences.

### C. Word Tokenization

```
var2 = word_tokenize(text)print(var2)
```

It divides a sentence into individual words and punctuation tokens.

Example:

Input:\
`I love Python!`

Output:

```
['I', 'love', 'Python', '!']
```

Difference between sentence and word tokenization:

| Sentence Tokenization           | Word Tokenization          |
| ------------------------------- | -------------------------- |
| Splits paragraph into sentences | Splits sentence into words |
| Uses `sent_tokenize()`          | Uses `word_tokenize()`     |

### D. Removing Punctuation

```
text = re.sub('[^a-zA-Z]', ' ', text)
```

It removes characters that are not English letters and replaces them with spaces.

Example:

Input:

```
Hello! I love Python 123.
```

Output:

```
Hello  I love Python
```

Viva: What is Regular Expression?

Answer: Regular Expression (Regex) is a pattern used to search, match, or replace characters in text.

### E. Removing Stop Words

Very Important

```
var3 = set(stopwords.words('english'))tokens = word_tokenize(text.lower())filtered_text = []for word in tokens:    if word not in var3:        filtered_text.append(word)
```

Stop words are commonly used words that usually carry less information for a particular text analysis task.

Examples:

- is
- am
- the
- a
- an
- and
- of

Example:

Input:\
`I am learning Python`

Output:\
`['learning', 'python']`

Why remove stop words?

To reduce unnecessary words and focus on meaningful terms.

### F. Stemming

```
ps = PorterStemmer()var = ["write", "writing", "wrote",       "writes", "reading", "reads"]for w in var:    print(ps.stem(w))
```

Stemming means reducing words to their root-like form by removing word endings.

Output from your notebook:

```
write
write
wrote
write
read
read
```

Important: Stemming does not always produce a meaningful dictionary word.

Example:

- Playing → Play
- Reading → Read
- Writes → Write

### G. Lemmatization

```
wordnet_lemmatizer = WordNetLemmatizer()text = "studies studying cries cry"tt = nltk.word_tokenize(text)for w in tt:    print(wordnet_lemmatizer.lemmatize(w))
```

Lemmatization converts words into their meaningful dictionary base form.

Output:

```
studies → study
studying → studying
cries → cry
cry → cry
```

Difference between Stemming and Lemmatization:

| Stemming                  | Lemmatization                |
| ------------------------- | ---------------------------- |
| Removes word endings      | Finds dictionary base form   |
| May produce invalid words | Produces meaningful words    |
| Faster                    | More linguistically accurate |
| Uses PorterStemmer        | Uses WordNetLemmatizer       |

### H. POS Tagging

Important for viva

POS stands for Part of Speech.

It identifies whether a word is a noun, verb, adjective, etc.

Code:

```
text = "Hello everyone this is a sample text! Earth."text = nltk.word_tokenize(text)nltk.pos_tag(text)
```

Output examples:

```
('Hello', 'NNP')('everyone', 'NN')('is', 'VBZ')('sample', 'JJ')('text', 'NN')
```

Common POS tags:

| Tag | Meaning                      |
| --- | ---------------------------- |
| NN  | Noun                         |
| NNP | Proper Noun                  |
| VB  | Verb                         |
| VBZ | Verb (third-person singular) |
| JJ  | Adjective                    |
| RB  | Adverb                       |
| DT  | Determiner                   |
| IN  | Preposition                  |

Viva: Why is POS tagging used?

Answer: To identify the grammatical category of each word in a sentence.

### I. TF-IDF

Most important

TF-IDF stands for Term Frequency–Inverse Document Frequency.

It is used to calculate how important a word is in a document compared to a collection of documents.

Your notebook uses:

```
from sklearn.feature_extraction.text import TfidfVectorizernew_sentence = "This is an example of term frequency. Meow meow meow meow meow!"def calculate_tfIdf(document):    tokenizer = TfidfVectorizer()    tf_matrix = tokenizer.fit_transform(document)    features_names = tokenizer.get_feature_names_out()    return tf_matrix, features_namesdocument = [new_sentence]tf_matrix, feature_names = calculate_tfIdf(document)print('TF-IDF')print(feature_names, tf_matrix.toarray())
```

How does it work?

- TF (Term Frequency): How frequently a word appears in a document.
- IDF (Inverse Document Frequency): Measures how rare or common a word is across documents.
- TF-IDF: Gives a higher importance to words that are frequent in a document but less common across the collection.

Your notebook output:

Important observation

# 0.8839

TF-IDF score for the word "meow"

The word `meow` appears five times, so it receives a higher score than the other words in this single-document example.

Viva: Where is TF-IDF used?

Answer:

- Search engines.
- Document classification.
- Text mining.
- Information Retrieval.
- News categorization.
