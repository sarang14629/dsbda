## 9. Outlier detection

Your notebook introduces outliers:

```

```

Q37. What is an outlier?

An outlier is a value that is unusually high or low compared with other values in a dataset.

Example: If most students have attendance between 50 and 95, attendance of 200 is an outlier.

Q38. What is IQR?

IQR stands for Interquartile Range. It measures the spread of the middle 50% of the data.

Formula:

\\[ IQR = Q3-Q1 \\]

Where:

- Q1 = First quartile (25%)
- Q3 = Third quartile (75%)

Q39. How do you calculate lower and upper bounds?

\\[ Lower=Q1-1.5(IQR) \\]

\\[ Upper=Q3+1.5(IQR) \\]

Q40. How do you handle outliers in your practical?

Your notebook uses the IQR method and replaces values outside the calculated limits with the nearest boundary.

```
def handle_outliers_iqr(df, column):    Q1 = df[column].quantile(0.25)    Q3 = df[column].quantile(0.75)    IQR = Q3 - Q1    lower_bound = Q1 - 1.5 * IQR    upper_bound = Q3 + 1.5 * IQR    df[column] = df[column].apply(        lambda x: upper_bound if x > upper_bound        else (lower_bound if x < lower_bound else x)    )
```

Q41. Does this method delete outliers?

No. It replaces extreme values with the lower or upper boundary. This is called clipping or capping.

Q42. Why do we handle outliers?

Because extreme values can affect statistical calculations and analysis.

## 10. Min-Max Scaling

Your final operation is Min-Max scaling.

Q43. What is data transformation?

Data transformation means converting data into a suitable format for analysis.

Q44. What is normalization?

Normalization is the process of scaling numerical values into a common range.

Q45. What is Min-Max scaling?

It converts numerical values into a range between 0 and 1.

Formula:

\\[ X'=\frac{X-X\_{min}}{X\_{max}-X\_{min}} \\]

Q46. Why do we use Min-Max scaling?

It brings values into a common range, making them easier to compare and useful for machine learning algorithms.

Q47. What is the output range of Min-Max scaling?

0 to 1.

Q48. What happens to the minimum value?

It becomes 0.

Q49. What happens to the maximum value?

It becomes 1.
