## 7. Outlier detection using IQR

This is a very important part of your practical.

Code:

```
Q1 = df[column].quantile(0.25)Q3 = df[column].quantile(0.75)IQR = Q3 - Q1lower_bound = Q1 - 1.5 * IQRupper_bound = Q3 + 1.5 * IQR
```

Understand the formulas:

- Q1 = 25th percentile.
- Q3 = 75th percentile.
- IQR = Interquartile Range.

Formula:

\\[ IQR = Q3-Q1 \\]

Outlier limits:

\\[ Lower=Q1-1.5(IQR) \\]

\\[ Upper=Q3+1.5(IQR) \\]

Any value below the lower limit or above the upper limit is considered an outlier.

### How are outliers detected mathematically?

Your notebook uses the IQR method (Interquartile Range).

Code from your notebook:

```
for column in df.columns[:-1]:    Q1 = df[column].quantile(0.25)    Q3 = df[column].quantile(0.75)    IQR = Q3 - Q1    lower_bound = Q1 - 1.5 * IQR    upper_bound = Q3 + 1.5 * IQR    outliers = df[        (df[column] < lower_bound) |        (df[column] > upper_bound)    ][column]
```

Important formulas:

\\[ IQR = Q3-Q1 \\]

\\[ Lower = Q1-1.5(IQR) \\]

\\[ Upper = Q3+1.5(IQR) \\]

A value below the lower bound or above the upper bound is considered an outlier.
