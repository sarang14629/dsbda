## 5. Mean, Median and Mode

This section calculates the average, middle and most frequently occurring passenger age.

### Step 1: Remove missing values

```
age_data = df['age'].dropna()
```

`dropna()` removes empty or missing age values.

### Step 2: Sort the ages

```
sorted_age_data = sorted(age_data)n = len(sorted_age_data)
```

- `sorted()` arranges ages in ascending order.
- `len()` counts the number of ages.

### Step 3: Calculate mean

```
mean_age = sum(age_data) / len(age_data)
```

Mean = Sum of all values / Number of values.

### Step 4: Calculate median

```
if n % 2 == 1:    median_age = sorted_age_data[n // 2]else:    median_age = (sorted_age_data[n // 2 - 1] +                  sorted_age_data[n // 2]) / 2
```

Median is the middle value after sorting.

- If the number of values is odd, take the middle value.
- If even, take the average of the two middle values.

### Step 5: Calculate mode

```
age_counts = Counter(age_data)mode_age = age_counts.most_common(1)[0][0]
```

Mode is the value that occurs most frequently.

## 6. Boxplot

[How to make a boxplot and interpret it](https://images.openai.com/static-rsc-4/Agb9ECZp0ggUuOr9qFMU83V2nKTVE5PU7I8IMu1N0ayYE-ppwVbD41hJwjEWQFWv44bf8Yo8A6HHeGy-T1u5LnHq5kJsavezUXoDQoKVyVJz9uIZITDeGfcPkqblYf62idyoZr9HF6snQg8TJZxEsvgOCw2MMo9jOY9zaXB5BdQ?purpose=inline)

Code:

```
plt.figure(figsize=(8,4))sns.boxplot(    x="sex",    y="age",    hue="survived",    data=df,    palette="viridis")plt.title("Distribution of age with respect to each gender and survival Status")plt.xlabel("Sex")plt.ylabel("Age")plt.show()
```

Explanation:

- `x="sex"` displays male and female categories.
- `y="age"` displays passenger ages.
- `hue="survived"` separates passengers according to survival status.
- `palette="viridis"` sets the graph colors.
- `plt.title()` adds the graph title.
- `plt.show()` displays the graph.

What is a boxplot?

A boxplot is a graph that shows the distribution of data using minimum, maximum, median, quartiles and outliers.

Remember: The line inside the box represents the median.
